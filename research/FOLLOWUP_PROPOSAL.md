## 3. 下一方法：让模型知道已经说了什么，并保留证据上下文

### 3.1 最小可行改动

1. 从已有描述 T 提取实体指代与已知事实状态 K。区分同类不同实例；定位不确定时保留多个假设或弃答，不能强行合并。
2. 用固定的自动 grounding 模型定位提及实体，同时保留一小组图像驱动候选，避免只找文本已有物体。禁止使用测试 gold 事实、框或隐藏问题来生成候选。
3. 构建保留背景的实体框、扩张框，以及可能关系两端的联合框。关系候选由可见几何/图像信息及 T 决定，规则和数量在开发前固定。SAM mask 只作对照，默认不把背景抹黑。
4. 固定观察器读取 **T + 全图缩略视图 + 所选区域**，生成有限的原子事实，记录实例、证据区域及不确定性。全图与 ROI 必须显式说明来自同一图像，避免被当成两个场景。
5. 对事实做已有文本蕴含检查、实例绑定和跨观察去重。该过程产生预测，独立标注才给出评估真值。
6. 在动作确有剩余收益后，训练预测新增正确事实与错误风险的选择器；动作包括全图、实体、关系视图与 STOP。

全图是正规动作，不把区域方法强加给所有图片。若实例本来就能从全图看清，允许选择全图或停止。对同一动作池、同一生成结果和相同预算，枚举 oracle 应不低于池内全图动作；违反时先检查实现、标签或预算条件。

### 3.2 两个可证伪的方法家族

**A：条件观察价值。** 使用自动候选、全局上下文和 K，预测每个动作的实际边际收益。若初始全图补充为 B，则进一步观察的收益相对 `T + B` 计算；部署决策不能预先读取全部昂贵 crop 描述。预测器可用 cross-attention 或小型 LoRA，先做直接回归/排序，不先上 RL。

**B：全图事实筛选。** 如果合适 ROI 仍不增加证据，保留全图并生成带实例对应的候选事实集合，再学习基于 T 的未覆盖事实选择、去重和弃答。这仍服务于原目标，但转移了方法瓶颈。必须打过“全图结构化抽取 + NLI 去重”和强全图补写；不能将标准拼装当作已成立的新意。

A、B 按诊断结果选择，不同时无限扩张。若两者均受观察器感知限制，再固定选择规则比较分辨率或另一观察器；换大模型仅是组件诊断。

### 3.3 候选 novelty 与验证

潜在贡献是 **以已有事实和同实例绑定为条件，学习观察/表达的实际新增价值**。成对描述监督应满足：

- 同一图片补充了某个事实后，重复获得该事实的价值下降，但其他未覆盖细节可能仍有价值。
- 同义改写不应导致无理由的价值变化。
- 同类不同实例的属性不能互相替代；关系需要两端都成立。
- 已覆盖事实与无法辨认事实应触发不同的停止/弃答行为。

要证明这些结构带来超越强 planner、全图补写和语义去重的收益，并在相同组件/监督/成本下成立。更换 detector、保留全图、scene graph、ranking loss、NLI 或 STOP 单独都不是新意。若只获得工程提升，先记录该进展，再继续寻找并验证方法贡献。

## 4. 第一轮必须做的原因区分实验

### R0：证据与标签

- 已用的 100 图及 500 caption 全部保留为开发诊断材料。完成已有 80-context 停止审核；它是分层挑选，另加随机抽样审核来估计一般错误，不能混报其错误率。
- 分别标注：目标事实是否可见、候选是否包含证据、观察器是否识别、实例是否一致、T 是否已包含、最终是否多写/错写。使用两位独立审核者及裁定；自动模型只作预筛。
- 新增 200–300 张去重开发图，先对其中 100 张做深入审核；主要实例/事实标签的可裁定一致率目标约 90%，未达则修标签。数量是规划值，先冻结抽样清单。
- 原子事实清单非穷尽，清单外输出须盲法补核，不能直接算幻觉。评审应看到原始全图、T 和必要证据，不只看可能已裁掉关系的 ROI。

### R1：几何、文本条件与全局上下文

第一步复现旧对照的输入与 prompt 差异，然后进行冻结的因子实验：

| 因子 | 取值 |
|---|---|
| 区域生成 | 旧 grid、自动实体框、扩张实体框、关系联合框 |
| 文本条件 | 不看 T；看相同 T 并要求补充同类事实 |
| 观察上下文 | ROI 单独；全图缩略图 + 同一 ROI |

固定模型 revision、解码、实例输出格式和最终文字预算。先在同一小型开发块跑完整对照，确认作用后再扩量；不把改变多个因子的最终差值全部归因给 segmentation。

这里“不看 T”只消融 observer 的文本输入，同一状态下冻结并共享候选池。自动候选本身可能由 T 引导定位，因此该对照不能称为整个系统 text-independent。完整的 caption 必要性另设纯图像 proposer/planner 与不读取 T 的选择策略，并单独统计两条路径成本。

必须同时运行：一次全图补写；提高分辨率全图；相同调用数的二次全图审阅；全图+重复全图输入；全图结构化事实抽取+蕴含去重；旧 grid 加同样的 caption/global 条件。可选 mask 与人工框上界放在明确标记的诊断子集。

自动框可能漏检；人工框优于自动框才支持优先修定位。全图+ROI 优于 ROI-only 才支持上下文丢失假设。多个 crop 中挑最优的离线 oracle 仅是上界，不能冒充可部署结果。

### R2：强 baseline 之后还有多少剩余价值

- 先看动作池识别上界能否在相同预算下增加已核验事实；再看简单/提示式可部署策略能否取得一部分收益。
- 对所有方法相同的初始全图补充 B，比较 `T+B+所选观察` 与 `T+B+再次全图审阅`；统一最终输出 token 上限，计入 B 与二次调用。把多调用一次的效果与选择证据的效果分开。
- 第二次 observer、选择器和事实去重模块都读取同一个已知状态 `T+B`；B 中可能有错误，不当作 gold，最终错误也需评分。缓存显式包含 B 的内容/hash、生成模型 revision 和 prompt。不能仍只给 T，却把收益解释成“相对 T+B 的剩余价值”。
- 从自然 caption 出发独立构造事实覆盖变化和忠实改写；不再用模型输出直接拼接制造“饱和”。“饱和”仅相对于审核后的目标事实集合，并对新发现事实单独裁定。
- 报告观察后的新增事实、选择 regret、已知事实重复、错误绑定、无收益动作和 STOP 校准。动作有并列最优时，不要求单一动作 ID 完全一致。
- 建议推进门槛：新动作上界相对预指定最强全图控制的 coverage 增量至少约 5pp，图像配对区间下界 >0，且没有不可接受的新增错误；这是新协议规划，不是对旧 10pp 失败门槛的事后改写。只在 R0 后、看新结果前冻结实际阈值与样本量。
- 若只在特殊子群有效，按预声明类别报告覆盖比例和全体结果；不能事后只保留成功图片。

## 5. 指标与成本公平性

令 F 是每图独立裁定的事实集合，E(T) 是 T 已覆盖事实。主要质量指标为新增正确覆盖比例
`(|E(T_after) ∩ F| − |E(T_before) ∩ F|) / |F|`，先对每图的 caption 状态平均，再对图片平均。报告对象/属性/关系分项、严格同实例子集、新增正确事实数、错误新增数及重复率。

主输出预算先取统一 tokenizer 的 96 tokens；48/96/192 作为成本曲线，不在测试后挑获胜点。源 caption 不计入新增文字，但所有处理调用计入计算成本。全图残余实验中，各方法最终总补充长度一致，不能让我们额外堆文字。

预声明新增事实错误率非劣界（初始建议 +2pp，置信区间上界也需满足），同时报告每例错误事实数，避免靠减少输出人为改变分母。隐藏视觉 QA 可作辅助 reader 端点；不能将测试 QA、答案、实例 gold 或未来市场标签送进选择器。

**成本按完整路径核算：** grounding/segmentation、全图编码、montage/planner、所有实际观察、NLI/reranking 和解码。记录 processor 后的 `image_grid_thw`、实际视觉 token、文本输入/输出 token、耗时与显存；多图合计。框面积只作几何描述，不能替代推理成本。缓存命中与冷启动分别报告；部署不能免费使用训练时枚举的候选观察。

先做相同最终输出长度的质量比较，再做相同总视觉 token/计算预算的比较；若不能精确匹配，给质量—成本曲线，不能称严格 equal-compute。更大模型、更高分辨率和更多调用分别归因。

## 6. 从开发到课程正向确认

| 阶段 | 工作 | 完成或转向条件 |
|---|---|---|
| R0 / E0 | 审核、实例事实、旧失败归因、新开发拆分 | 有可靠可裁定标签；标注缺口公开记录 |
| R1 / E1 | 几何 × 文本条件 × 全局上下文 | 明确哪个改动有帮助，或证伪该解释 |
| R2 / E1–E2 | 相对强全图控制的剩余空间、上下文必要性 | 有真实动作空间再训练 A；没有则转 B |
| R3 / E3 | 实际收益学习、三 seed、强规则与提示基线、机制消融 | 验证集建议 ≥3pp coverage 增益，配对区间下界 >0，错误非劣；新数据前锁定门槛 |
| R4 / E4 | 锁定模型/指标/比较对象；全新确认集与人工检查 | 独立正向、可复现且有明确前作差异，达到课程标准 |
| R5 / E5 | 跨域/观察器/reader、质量成本、多步和停止机制 | 成立后形成 CVPR 级证据链，再开展 finance |

课程规模可从 3,000 训练图、500 验证图、500 独立确认图规划，以开发集方差和最小有意义效果调整，而不是保证该规模足够。独立图像/重复群才是统计单位。同图多 caption、多个 crop 不能伪装成独立样本。训练集可用 VG/COCO 相关标注，但缺标不作负事实；与 CompreCap、CompositionCap 等外部来源检查重叠。

CompositionCap 可作为区域属性评估参考，实际标签/许可适配后再决定使用；不要将其公开测试当训练集后仍称外测。已用于调设计的任何外部数据都降为开发。新确认集只能在设计锁定后打开。

## 7. 如果下一方法仍然失败，必须怎样继续

目标是做出可靠正向效果，执行方式是持续改进方法。一次失败不结束任务，也不要求立即换到无关题目。

| 失败现象 | 下一轮有针对性的重设计 |
|---|---|
| 人工区域有增益、自动区域没有 | 修 grounding、实例消歧、候选召回；比较另一自动 proposer |
| 联合全图有益、孤立 crop 有害 | 保留全局视图，研究哪种证据范围适合属性/关系 |
| mask 更准却 caption 更差 | 恢复背景，使用框/关系联合区域；不以 segmentation IoU 代替事实收益 |
| 观察器看不出人工确认的可见细节 | 固定选择规则，比较分辨率或另一观察器，分离感知和决策 |
| 新动作 oracle 有空间、学习器没有 | 检查实际收益标签、同实例编码、成对监督和不确定性校准 |
| ROI 无增益、全图抽取仍有遗漏 | 转 B：全图事实集合的条件选择/压缩，重新核查 prior art |
| 模型评审有提升、盲审没有 | 修评估与事实粒度，暂停以该代理标签训练 |
| 质量有提升、同费用比较没有 | 优化调用/共享编码/停止策略；不能宣称效率胜出 |
| 只有 prompt/现成组件提升 | 保存工程正向结果，继续检验机制；不宣称方法 novelty 已完成 |

每轮必须产生：失败证据 → 文献/code 更新 → 新假设 → 区分原因的对照 → 固定指标与分割 → 有限作业队列 → 开发结果与下一决定。连续两个同类变体失败时更换方法家族，而非无限调参。

在授权资源内自主推进这一循环直到满足独立正向及新意目标；资源/人工数据阻塞时明确报告，继续可独立推进的准备。若多个公平、可靠方法家族都否定具体假设，报告证据并讨论收窄任务；不能承诺数学意义上“必然成功”。

确认集若影响新设计，立刻归为开发，下一次确认使用新数据。保存所有 seed、失败配置和主要终点；不得反复查看同一测试集直到显著、删负结果或事后换主指标。

换新的 holdout 只能避免数据泄漏，不能自动解决跨轮反复确认的假阳性。首次正式确认前预注册项目级确认次数与 alpha 分配，跨方法版本共享，不能改个方法名就重置。初始方案为最多两次确认，每次双侧 alpha=0.025，主增益使用 97.5% 区间，总计不超过 0.05；若增加主要比较，还需相应控制多重性。报告所有确认尝试。额度用完后的迭代继续属于开发，不能再拿一个未经调整的 95% 区间宣布完成。开发筛查的 95% 区间仅作描述性决策依据。

## 8. 实现状态与下一轮交接

已有 acquisition schema、旧候选、观察/评估脚本、缓存和审核导出可复用；新方法**尚未实现或运行**。原 `observe.py` 的缓存是 caption-independent，不能直接当 caption-conditioned 新观察复用。

下一实现顺序与验收产物见 [METHOD_REDESIGN_PLAN.md](METHOD_REDESIGN_PLAN.md)。重点增加：自动 grounding adapter；context_id 与全图/ROI 联合输入；关系候选；完整成本计数；独立事实审核；R1 因子运行清单；R2 剩余效用；有限任务队列和独立监控。保持 gold/public 边界。

缓存必须包含 image hash、context hash、候选/实体 ID、全图与 ROI 输入模式、模型 revision、prompt hash、processor 参数和解码设置。同一 crop 随 T 变化后的生成不能共用同一观察标签。旧指标文件、历史 proposal PDF 和失败脚本保持原样供复现。

## 9. GPU 与连续执行：项目固定使用 L4

按用户最新要求，项目后续固定使用 L4，从一张 `g2-standard-12` L4 开始。继续冻结 3B 推理，grounding、可选 mask、观察器按阶段缓存加载。历史 acquisition 峰值 torch 显存约 7.4–7.7 GiB，说明已完成负结果不是显存不足的证据；新多图/分辨率组合仍须实际 profiling。

L4 标称 24GB。下一轮先测 batch 1/2/4/8 等有限配置，按视觉 token 分桶，保留显存余量，记录有效输出/秒、峰值/保留显存、GPU 利用率和 CPU/I/O 等待。若配置放不下，调整模型规模、分辨率、batch、阶段加载与适配训练方式，并披露相应限制；保持 L4 硬件选择。详细依据与来源见 [资源计划](../hpc/RESOURCE_PLAN.md)。

**GPU 有效占用是每次执行和交接必须记住的重点。** 每 5 秒独立记录利用率、显存和进度；稳定计算阶段可行时争取 70–90% 或更高，低于 30% 持续两分钟或进度停滞必须诊断。提前下载/预处理、写好代码和恢复命令，batch/prefetch/cache 供数；主作业运行时 subagent 并行准备下一必要任务，统一调度和预算，不抢同一设备。

保留有限、已准备好的必要任务队列，在不越过研究门槛的前提下衔接。不能用空烧、重复已完成实验或偷跑 holdout 来维持表面占用。装载、CPU/人工阶段可能短暂下降，真实连续吞吐比瞬时 100% 更重要。

**不得手动释放、取消、scancel 或重启现有 CPU/GPU 分配。** 在同一 allocation 内正常结束实验进程、卸载模型并启动下一准备好的任务可以；保留节点会话、检查点及缓存，由服务器处理回收。没有有效 GPU 任务时如实记录阻塞并继续准备，不造假负载。

研究规模不按旧 pilot 小时数压缩，但提交前必须核对授权余额、实时 Slurm 记账与多卡累计使用。课程 300 GPU hours 不代表可全部消耗。本地这次修改没有连接 HPC、启动作业或验证远端实时占用。

## 10. 从课程到 CVPR 级工作

**课程标准：** 一个通过独立确认的正向方法，强全图及区域基线、可靠事实评估、两个以上关键消融、复现代码和明确但不过度的新意陈述。可靠工程收益是阶段进展，单靠换模型不满足用户的 novelty 要求。

**CVPR 目标：** 证明具体的新方法结构，而非成熟工具组合：在相同图片不同知识状态下实际新增价值可学习；同实例关系及信息覆盖的监督是必要的；对新 caption 来源、实体组合、观察器及领域可迁移；效应在完整费用和事实错误约束下成立。按开发方差规划更大训练集及至少双域独立测试，避免先追规模再找问题。

**长期期刊目标：** 若一步机制成立，研究多步事实状态、关系证据协同、停止校准与质量成本规律。是否有二/三步空间先测上界，不能仅把 RL 或更大模型当作贡献。金融下游用于验证外部价值，不能替代上述 CV 证据。

## 11. Finance downstream：在 CV 主线成立后检验应用价值

### 定位与假设

先完成 CV 核心验证和课程版本，再完成 CVPR 级方法证据，最后正式开展 finance downstream。前期可整理数据来源与时间字段，但不能挤占核心实验。金融结果不是课程项目或 CV 方法成立的必要条件；若下游失败，保留结果，不倒推或改写已经独立确认的 CV 结论。

**D1 假设：** 在完整新闻正文及图片说明已经给定时，选择出的新增、可核验视觉事实，仍能改善财经事件理解。**D2 条件假设：** 这些事实在已有文本、价格及其他可用信息之外，对预先指定的市场变量还有预测增量。D1 成立不意味着 D2 成立，两者都不能提前声称有正结果。

例如正文说“工厂发生火灾”，照片可能补充“可见某厂房屋顶坍塌”，但不能仅凭照片推断停产时长、公司损失或股价方向。若正文或图片说明已经交代屋顶情况，这就不是新增事实；若照片是旧图，更不能当作当前现场证据。

### 新意边界

金融图像包含有用信息不是新发现：[JFE 2022 的新闻照片研究](https://doi.org/10.1016/j.jfineco.2021.06.002)已研究照片悲观程度与市场行为以及图文信号的替代关系；[JBEF 2023 的图像信息研究](https://www.sciencedirect.com/science/article/pii/S2214635023000655)已研究图像相对文本的额外信息与融资结果。因此，我们可能的贡献仍是**已有文本条件下的观察价值学习及其跨域迁移**。换成财经数据、情绪特征或加一次市场回归都不能单独算方法 novelty。

### D1：财经事件理解

1. 先审核约 300 组新闻—图片，确认合法数据访问、完整正文/图片说明、发布与更新时间、图文实体对应、照片来源与拍摄时间。区分现场照片、资料图、logo 和图表；主实验先聚焦可核验的事件照片，其他类型单列。时间或对应关系不明的样本保留 unknown，不能推断现场状态。
2. 主输入为观测时刻可获得的**完整正文 + 图片说明**。标题或摘要条件只作次要分析，不能把正文已有的信息标成图片独有。若全文超长，统一分块/检索策略并报告丢失信息风险，不让方法间输入不同。
3. 独立标注可见事实、支持区域及与事件有关的问题，例如受影响对象、可见物理状态、人物与物体关系。由独立审核者核验，不以自动模型输出充当人工真值。测试问题和市场结果不得输入选择器；事件相关性准则在看结果前确定。
4. 固定下游 reader，比较：文本；文本 + 全图；文本 + 通用图像描述；文本 + 我们选择的新增事实；文本 + 随机/错配图像。还需包含 CV 阶段最强选择 baseline，统一生成器与输出预算，同时报告全图方法的实际成本。错配图像用于诊断图像依赖，不能替代强基线。
5. 主要端点是有依据的事件理解准确率/事实恢复率，辅以错误新增、重复和弃答校准。按新闻事件及重复图片分组隔离划分，防止同一照片跨 train/test。先测冻结选择器的零样本迁移，再单列金融域训练，不能混报。测试规模根据开发集方差规划，锁定后独立确认。

### D2：市场预测，仅在 D1 与数据条件通过后启动

- 在查看测试结果前固定一个主要目标、预测时点和预测期。例如有日内成交数据时研究下一交易日 realized volatility；只有日线时可研究绝对收益，但明确它只是不同的波动代理。异常成交量和收益方向列为次要目标并处理多重比较，不能事后挑最显著指标。
- 严格按首次可用时间建样本：图片、正文更新和价格特征必须在预测时点可见；盘后新闻按后续可交易时点处理。记录原始时区和统一时间，禁止把后续更新全文放回最初发布时间。
- 使用时间顺序的滚动训练/验证/测试；对重叠预测期设置隔离窗口，对同事件、多来源转载、重复照片做聚类和去重。评估预训练模型可能知道历史事件后果的泄漏，优先采用训练截止之后的数据；匿名化只能作补充诊断，不能声称消除了泄漏。
- 保持相同预测模型，比较历史价格/成交量、再加全文文本、再加全图或通用描述、再加所选事实。控制文本情绪、来源、图片类别和时间等可观测因素，报告按事件或时间块计算的不确定性。预测增量不能直接解释为因果效应或可交易收益。
- 只有独立时间段出现稳定增量，才报告金融预测支持；若没有，结论限于 CV 与 D1 的已验证效果。不能为了正结果反复更换市场目标、窗口或测试集。

### 实施与产物

在核心 E0–E5 管线完成后，增加新闻适配器、时间可用性检查、重复图文分组、事件事实标注、固定 reader 和滚动市场评估模块。补充字段：`article_id, event_id, entity_id, source, first_available_at, updated_at, image_available_at, image_capture_time_status, text_version, photo_type, duplicate_group, prediction_time, target_horizon`。市场标签与模型可见输入分库存储；发布时遵守来源许可，必要时只发布 ID、标注及获取流程。

本节是后续设计，尚无实现或实测结果。当前应写和跑的仍是 R0–R2（修复并验证 E0–E2）；不得跳过 CV 验证直接扩大金融实验。


## 当前执行决定
